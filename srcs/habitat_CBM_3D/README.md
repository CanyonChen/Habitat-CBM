# Habitat-CBM 3D Scripts

This folder contains the 3D companion scripts for `repo/models/habitat_CBM_3D.py`.

## Data Contract

- Input split root: `splited_data/{train,val,test}` with the existing `conventional/` and `functional/` layout.
- Image input: one patient-level 3D tensor per sample, shaped `[4,D,H,W]`.
- Channel order: `t1,t1ce,t2,t2flair`.
- VOI source: `functional/voi`; it is used only to crop the volume and is not appended as an input channel.
- Concept assets: reuse `concept_labels.csv` and `concept_scaler_stats.json` generated by `build_habitat_cbm_labels.py`.

## Main Commands

```bash
python repo/srcs/habitat_CBM_3D/train_habitat_CBM_3D.py \
  --config repo/srcs/habitat_CBM_3D/args_train_habitat_CBM_3D.json \
  --run-id run01 \
  --device cuda:0
```

```bash
python repo/srcs/habitat_CBM_3D/eval_habitat_CBM_3D.py \
  --config repo/srcs/habitat_CBM_3D/args_train_habitat_CBM_3D.json \
  --checkpoint /path/to/stage3_best.pt \
  --run-id run01_eval \
  --device cuda:0 \
  --splits val,test
```

```bash
python repo/srcs/habitat_CBM_3D/eval_habitat_cbm_3D_concepts.py \
  --patient-concepts-csv /path/to/patient_concepts_habitat_cbm_3d_run01.csv \
  --output-dir /path/to/concept_eval \
  --split test \
  --scale raw
```

```bash
python repo/srcs/habitat_CBM_3D/intervene_habitat_cbm_3D.py \
  --checkpoint /path/to/stage3_best.pt \
  --patient-predictions-csv /path/to/patient_predictions_habitat_cbm_3d_run01.csv \
  --patient-concepts-csv /path/to/patient_concepts_habitat_cbm_3d_run01.csv \
  --concept-scaler-json /path/to/concept_scaler_stats.json \
  --output-dir /path/to/intervention \
  --split test
```

```bash
python repo/srcs/habitat_CBM_3D/run_habitat_cbm_3D_5fold_cv.py \
  --base-config repo/srcs/habitat_CBM_3D/args_train_habitat_CBM_3D.json \
  --output-root /root/autodl-tmp/habitat_CBM/results/habitat_CBM_3D_5fold_cv
```

## Notes

- Set `model.pretrain_path` in the JSON to use MedicalNet-18 pretrained weights.
- Use a smaller `data.target_shape`, for example `[8,32,32]`, for CPU smoke tests.
- Set `train.use_monai_augmentation=false` if MONAI is not installed.
